- **A real, pre-existing backend bug found and fixed** (not part of the original 5A-3 brief, but blocking the requested live verification, and confirmed by code + a decoded live JWT, not guessed): Keycloak's `rehletshifaa-web` client never mapped `auth_time` onto issued access tokens (no protocol mapper existed at all for it). `AccessIdentity.current()` (`backend/.../access/application/AccessIdentity.java`) reads `auth_time` via `getClaimAsInstant`, and falls back to `Instant.EPOCH` when the claim is absent — so **every `recent_auth`-gated capability** (`access.assignment.manage`, `credential.verify`, `provider.activate`, role publish/retire/simulate) was unconditionally denied with `RECENT_AUTHENTICATION_REQUIRED` regardless of how recently a user had actually signed in, for every account, always. Verified by decoding a freshly issued access token client-side: `auth_time` is now present and within seconds of `iat`. This is a **Phase 1 Access Governance defect**, not introduced by Phase 5A and not scoped to provider/pricing/availability — recorded here because it was found and fixed in this session, with real evidence (JWT decode, before/after), not asserted from UI symptoms alone.
- **A second, narrower, evidenced inconsistency** (found by code reading, not exercised live): `AccessQueryService.effective()` (used by the Access Governance "Effective access" review panel) always constructs a synthetic actor with `Instant.EPOCH` when computing the displayed capability decisions — `// The target user's recent-auth claim is unknown; never borrow the administrator's authentication.` — **even when the reviewed subject is the caller reviewing themselves**, unlike `AccessQueryService.simulate()` a few lines below, which explicitly special-cases `actor.subject().equals(input.subject())` and reuses the real, current `actor`. Recorded as Phase 5B Access Governance UI follow-up, not fixed this session (out of Phase 5A-3 scope, and the user directed that only evidenced backend inconsistencies be recorded, not assumed ones — this one has a direct code citation).
